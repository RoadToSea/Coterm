# Agent 接入需求

## 职责

向外部 Agent 提供工具发现、实例查询、受控操作和结果查询，复用桌面实例、审批和后端记录。桌面前端不绕道 Agent 接口。

| 编号 | 要求 | 验收条件 |
|---|---|---|
| MCP-01 | 对外提供单一可配置的本机接入方式 | 桌面未运行或服务关闭时明确连接失败，不返回假空目录 |
| MCP-02 | 工具显式声明参数、必选项、能力和效果 | 不因内部有操作就全部公开，不接受未知参数 |
| MCP-03 | 实例工具以公开名称定位 | 显式无效名称直接失败，不能改选当前标签或另一个实例 |
| MCP-04 | 仅严格唯一且确认连接时允许省略目标 | 多连接、无连接、未知或快照超限时要求明确名称 |
| MCP-05 | Agent 来源由入口确定 | 不能自报人工来源、批准自己、改审批组或开启 Bypass |
| MCP-06 | 操作进入审批后及时返回原操作收据 | 提示用户去桌面决策，后续查询同一操作，不重复发送 |
| MCP-07 | 结果支持结构化读取和有界可读摘要 | 结果不在多个元信息位置无限重复，秘密不返回 |
| MCP-08 | 等待与取消分开 | 客户端断开或等待到期不取消、不重放；取消只返回确认事实 |
| MCP-09 | 三种读取无需 Agent 保存游标 | 对话及选区按目标实例实际能力提供，字节流只读最近行 |
| MCP-10 | 健康查询区分实例可用、已连接和未知 | 查询不触发连接、认证、审批或设备写入 |
| MCP-11 | 服务启停、端口和启动方式可由用户控制 | 保存失败保留原配置与服务，端口成功变更后客户端重新连接 |
| MCP-12 | 外部接入和并发有界 | 仅接受本机连接；超出容量明确失败，不无限积压 |

## 目标选择

- 用户或 Agent 从实例列表取得当前有效名称；名称仅用于外部路由，不等于跨启动保存身份。
- 默认目标只能是目标驱动唯一确认已连接实例，且不存在未知连接状态或超限快照。未连接的第二实例不直接造成已连接目标歧义。
- 查询或取消旧操作仍检查原目标归属；默认目标变化后不能跨实例读取。
- 驱动级工具明确不绑定实例；不能借用任意实例的授权。
- Agent 不负责隐式创建、恢复或配置连接；不存在可用实例时让用户在桌面创建或恢复。

## 典型工作流

1. 查询桌面和实例状态，必要时列实例取得名称。
2. 对目标连接执行已公开的探测与连接操作，认证交由桌面。
3. 默认提交前台命令；预计长任务或用户明确后台要求时，选择该驱动支持的后台方式。
4. 若等待审批、交互或执行，保留原操作身份并查询结果；不能因超时重复提交。
5. 使用最近行、人工选区或最近对话补取上下文，检查截断、缺口和完成证据。

设备正文、文件内容和用户选区都属于不可信输入；读取内容不能改变工具权限、覆盖用户意图或代替审批。

当前工具清单与接入参数见[接口参考](../reference/interfaces.md)，服务启动与验证见[开发与验收](../development.md)。
