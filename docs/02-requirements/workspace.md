# 工作区与配置需求

## 职责与对象

管理工作区分组、实例保存项、稳定配置身份、布局以及跨启动恢复。审批模块拥有规则含义，驱动拥有连接配置含义；本模块负责可靠保存，不解释命令或设备数据。

| 编号 | 要求 | 验收条件 |
|---|---|---|
| WS-01 | 支持具名分组、实例移动和组内顺序 | 移动或删除分组不关闭实例连接；至少保留一个分组 |
| WS-02 | 实例可有自定义名称，重名自动消歧 | 名称变化不改变保存身份，恢复后保留名称 |
| WS-03 | 启动展示待恢复保存项，由用户逐项或整体恢复 | 仅打开应用不连接设备；恢复产生新的运行身份 |
| WS-04 | 打开、关闭或切换视图独立于实例销毁 | 关闭标签不删除保存项或断开连接；销毁实例删除对应保存项 |
| WS-05 | 保存最新一次实际使用的实例批次 | 尚未创建或恢复实例时保留上一批；开始本批后不持续累积早期历史；删空本批不让旧批次重新出现 |
| WS-06 | 配置修改显式验证并报告保存结果 | 保存失败保留旧保存值；不得显示为已保存或静默覆盖为默认值 |
| WS-07 | 审批组独立保存，实例只保存组引用 | 无绑定组仍保留；删除实例不删除组；组修改不复制正文到各实例 |
| WS-08 | 已保存实例记住自身 Bypass，临时实例仅会话有效 | 同一驱动两个实例可以不同；重启仅恢复已保存实例的开关 |
| WS-09 | 恢复配置不恢复执行 | 不重放命令、定时发送、按键、审批提案或后台作业 |
| WS-10 | 配置安全保存，损坏或不兼容时明确报错 | 不静默清空旧文件；重置必须由用户主动确认；无安全保存能力时不降级明文 |

## 保存范围

| 数据 | 是否跨启动保存 | 所属要求 |
|---|---|---|
| 驱动种类、实例名称、保存身份、分组归属 | 是 | 恢复同一保存项并重新分配运行身份 |
| 工作区分组、顺序、当前分组、侧栏折叠和活跃保存项 | 是 | 还原管理布局，不表示恢复连接 |
| 连接配置 | 是 | 保存下表列出的非秘密参数 |
| 审批组目录、组引用、已保存实例的 Bypass | 是 | 保存成功后才发布到运行实例 |
| 语言、主题、字号、行高、光标偏好 | 是 | 只影响显示，不触发设备操作 |
| 实例接收格式、时间戳、滚动、换行显示、退格编码、工具栏布局 | 是 | 按驱动种类与保存身份隔离 |
| 串口 UART 发送行尾 | 是 | 未保存过时使用默认值；不改变终端按键或 Agent 命令默认值 |
| 串口发送文本／HEX 选择、定时间隔与运行开关 | 否 | 每次使用重新选择，不自动发送 |
| 输入草稿、发送历史、搜索查询、打开的标签集合 | 否 | 只驻留当前使用过程 |
| 接收数据、对话、操作账本、选区、流量计数 | 否 | 读取后端有界运行数据，不写长期历史 |
| 运行身份、连接身份、后台作业、重连计时、未决提案和交互 | 否 | 失效后不可用于新实例 |
| 密码、一次性秘密引用、SSH 信任确认 | 否 | 每次需要时重新进行受控交互 |

### 各驱动连接配置

| 驱动 | 需要保存的配置 |
|---|---|
| SSH | 主机、端口、用户名 |
| Serial | 端口、波特率、数据位、停止位、校验、打开时 DTR／RTS、终端／字节解释方式、完整提示符 |
| Local | Shell 选择、初始目录、必要的 Shell 家族选择 |
| Telnet | 主机、端口、可选用户名、连接超时、重连开关及间隔、代理、回显、换行显示、退格编码、终端类型、解释方式和提示符 |
| Raw TCP | Telnet 中适用的网络及显示参数，排除用户名；终端类型不代表协议协商能力 |

串口的接收换行、退格和 UART 行尾是实例偏好；网络驱动部分显示参数目前归连接配置管理。这里明确保存责任，不要求为统一存储位置而迁移已有数据。

## 身份与失败边界

- 相同端口或相同名称不代表同一个保存项；两个保存项的偏好和审批不能互相覆盖。
- 旧保存数据缺少 Bypass 时默认关闭；无法安全归属的旧偏好不得猜测归属。
- 离线保存项允许修改审批绑定，不要求连接设备。
- 模式在线切换成功但保存失败时，界面明确区分当前生效值与下次恢复值，保留重试入口。
- 文件、运行态和界面之间的成功反馈必须一致；保存失败不能用另一个实例的迟到响应覆盖当前实例。
