# 通信驱动需求

## 公共职责

驱动负责真实连接、认证、设备收发、协议控制、输入输出归属和执行事实。审批判断、保存项、工作区布局和 Agent 目标选择属于其他模块。

| 编号 | 要求 | 验收条件 |
|---|---|---|
| DR-01 | 创建仅登记已验证的配置，显式操作才连接 | 打开配置、恢复或挂载视图不发送设备数据 |
| DR-02 | 人工终端与 Agent 操作同一连接实例 | 可见终端的目录与环境变化作用于该前台通道 |
| DR-03 | 有独立后台执行能力时由调用者明确选择 | 默认前台；等待超时不改走后台；后台是否继承环境明确告知 |
| DR-04 | 驱动报告实际可用能力与连接状态 | 不把所有驱动强行承诺为同一种 Shell |
| DR-05 | 每次重连或重启会话更换连接身份 | 旧提案、输入和选区不能进入新连接，不自动重放未确认写入 |
| DR-06 | 批次先整体校验，按顺序发送 | 参数错误不部分发送；超时、断线或取消停止余项 |
| DR-07 | 保存接收事实，区分流和错误类型 | 独立错误流单独保留；已合并则如实报告，不能从文字内容猜拆分 |
| DR-08 | 按交互方式提供 Shell 或字节流能力 | Shell 可有对话；字节流不因提供命令发送就被假设成 Shell |
| DR-09 | 通信参数和显示转换分开 | 换行显示、本地回显不能改写后端接收数据 |

## 能力差异

| 能力 | SSH | Serial | Local | Telnet | Raw TCP |
|---|---|---|---|---|---|
| 共享交互终端 | 是 | Shell 模式 | 是 | 是 | Shell 模式 |
| 字节调试视图 | 无 | 是 | 无 | 无 | 是 |
| 独立后台执行 | 是 | 无 | 是 | 无 | 无 |
| 输入／输出／错误记录 | 是 | Shell 模式 | 是 | Shell 模式 | Shell 模式 |
| 原始字节发送 | 人工终端输入 | 文本与 HEX | 人工终端输入 | 终端输入 | 文本与 HEX |
| 最近行读取 | 是 | 所有模式 | 是 | 是 | 所有模式 |
| 选区与对话读取 | 是 | 仅 Shell | 是 | 仅 Shell | 仅 Shell |
| 可配置自动重连 | 无 | 无 | 无 | 是 | 是 |
| 协议自身的加密 | 是 | 无 | 不适用 | 无 | 无 |

传输层是字节流不代表产品必须禁用 Shell；是否支持对话取决于实例当前解释方式及边界能力。Telnet 的协议封装与 Raw TCP 的字节透传也不能混用。

## SSH

- SSH-01：配置主机、端口和用户名，端口默认 22。连接前核对服务器指纹；探测不等于信任或认证。
- SSH-02：密码由桌面受控交互收集，不放入 Agent 参数或保存配置；指纹每次连接确认。
- SSH-03：前台命令保留当前交互 Shell 的目录、环境和身份；支持多行脚本与顺序列表，首个非零退出停止余项。
- SSH-04：后台使用独立 Shell，批次内可延续环境，不继承前台目录、环境或提权身份，也不承诺断线后存活。
- SSH-05：命令、文件读取和文件写入可显式要求提权；命令提权只允许后台方式，密码一次性使用；免密策略不得导致密码行被当命令输入。
- SSH-06：提供固定系统信息查询、单路径元信息、有限文本读取与原子写入；不把这些只读接口变成任意命令或本地文件代理。
- SSH-07：取消前台命令先请求中断，不能确认时报告未知；必要时重建共享 Shell，独立后台作业不随共享 Shell 重建。
- SSH-08：只保证已支持的远端 Shell 与认证方式；私钥、代理认证、多因素认证、文件传输和端口转发不视为已完成能力。

## Serial

- SER-01：配置端口、波特率、数据位、停止位、校验和打开时控制线；端口枚举不打开设备、不修改控制线。
- SER-02：同一端口不能同时分配给本驱动多个实例；端口固定后通过新建实例换端口。
- SER-03：终端与 UART 调试在同一实例切换，分别对应 Shell 与字节流；不在创建页再增加独立数据类型选择。
- SER-04：Shell 使用完整字面提示符，先观察当前提示符，再逐项发送并等待；允许按批次指定提示符。提示符出现只证明观察到边界，不证明命令成功。
- SER-05：Shell 记录合并输出，错误流保持空值，退出码未知；字节流不生成对话，只提供最近行读取，必要时保留定时捕获结果。
- SER-06：文本支持明确行尾，HEX 按原始字节发送，不隐式补行尾或解释设备协议。
- SER-07：在线连接配置修改仅允许解释方式与提示符，保留连接和原始接收数据；有命令批次时拒绝切换，旧提案与选区失效，回到 Shell 需重新观察提示符。
- SER-08：通信参数修改要求先断开；配置校验及保存成功后才继续连接。打开时控制线变化可能复位设备，必须由配置明确决定。
- SER-09：USB 拔出导致读写故障或连接停止后，状态必须反映断开；仅断开开发板而转接器仍在时，不根据无输出推断串口句柄已关闭。
- SER-10：停止接收时处理尾部与资源释放；不以暂停对向读取、丢弃控制字节或无限扩大缓存掩盖全双工失败。
- SER-11：已连接时允许人工单独调整 DTR／RTS；命令批次占用时拒绝调整。电平可能复位设备，手动控制不代表支持硬件流控握手。

## Local

- LOC-01：配置可选 Shell、初始目录和必要的 Shell 家族；无法解析或目录无效时明确失败，不悄悄启动另一个解释器。
- LOC-02：显式启动或重启本地终端，退出后保留实例与有界记录，重启更换会话身份。
- LOC-03：已支持的 Shell 家族分别处理前台命令边界，不能假设所有解释器兼容同一种脚本；不支持时拒绝结构化执行。
- LOC-04：前台保留目录和环境，后台独立执行；列表首个失败停止。人工原始按键不自动推断为可靠对话。
- LOC-05：中断请求不等于终止；没有完成证据时保持未知和通道占用，直到确认边界或用户重启。
- LOC-06：后台取消只承诺实际确认的进程范围，不承诺完整后代进程树一定退出。

## Telnet 与 Raw TCP

| 配置 | Telnet | Raw TCP |
|---|---|---|
| 目标与端口 | 主机必填，端口默认 23，可改 | 主机必填，端口默认 8080，可改 |
| 用户名 | 可选，仅在登录提示后预填一次 | 不提供 |
| 超时、重连、代理 | 可配置 | 可配置 |
| 本地回显 | 默认按协议协商 | 默认开启 |
| 接收换行 | 默认不补全 | 默认对单独 LF 补 CR |
| 退格 | 默认 DEL，可选 BS | 默认 BS，可选 DEL |
| 终端类型 | 对端请求时上报支持类型 | 不进行终端类型协商 |
| 解释方式 | 界面提供终端 | 可切换终端与字节调试 |

- NET-01：配置保存后显式连接；初次失败不自动重试。仅已成功连接后的断线可按用户配置重连，使用有上限退避。
- NET-02：手动断开、取消连接和销毁实例停止重连；重连使用新身份且不重放按键、命令或定时发送。
- NET-03：代理只建立无认证的网络隧道，不启动外部代理程序；不支持的认证或加密明确拒绝，不声称代理使明文协议加密。
- NET-04：Telnet 处理支持的回显、窗口、终端类型和字节协商，控制帧不进入设备正文或正文计数；不承诺支持所有设备扩展。
- NET-05：Telnet 密码由人工终端输入，不保存密码、不提供通用自动登录脚本；Raw TCP 不虚构账号认证。
- NET-06：Raw TCP 的 HEX 路径保留任意字节；文本只是显示解释，不能把两种连接限制成“只支持 ASCII”。
- NET-07：Shell 采用完整提示符观察，不虚构退出码或错误流；字节流及 HEX 发送只确认发送，设备完成仍未知。
- NET-08：事件遗漏后能重新查询连接状态，避免最后一条断线事件丢失造成界面一直显示开启。
