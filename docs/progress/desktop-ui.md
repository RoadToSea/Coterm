# 桌面界面与主题

本文件跟踪桌面基座视觉、交互和主题支持。通用界面约定见 [桌面外观架构](../architecture/desktop-appearance.md)。

## 当前能力

- 桌面界面采用 shadcn/ui 与 Tauri 桌面交互模式；保留真实状态刷新、宿主 API 和审批流程。
- 外观支持浅色、深色和跟随系统，偏好持久化；插件 Shadow DOM、SSH/串口终端和 UART 调试台同步主题。
- 主题启动时提前应用；窗口间偏好变化可同步，终端颜色/搜索观察器在卸载时注销。

## 2026-10-30 主题改造与验收

- 调整工具栏、插件/实例导航、状态计数、对话框、离线安装、加载与空状态；新增 Radix 源码组件，保留 Tailwind 3 和 React 18。
- 右上角提供太阳/月亮/显示器三种外观选择，默认跟随系统并保存偏好；强调按钮使用独立前景，保证浅色模式可读性。
- SSH 与串口 Shell 原地更新终端背景、文字、光标、选区及 ANSI 颜色；搜索高亮同步。UART 发送框与接收区跟随主题，不改变人工发送方式或 MCP 命令队列。
- 验收覆盖宿主及插件生产构建、前端回归、真实 bundle 浏览器检查；检查两种配色、偏好恢复、系统跟随、多个窗口尺寸、终端内容保持和既有复制/粘贴/搜索/审批流程。
- 该浏览器验收使用宿主契约替身，不代表远程 SSH、物理串口或 macOS/Linux 原生验收。

## 后续关注

- 继续保持高密度桌面操作界面的可读性与窄窗口布局。
- 主题改动需验证插件 Shadow DOM、终端 ANSI 色彩及多窗口偏好同步。
