# 桌面界面与浅色/深色模式

日期：2026-10-30。

## 完成内容

- 按 shadcn/ui 与 Tauri 桌面交互模式调整工具栏、插件/实例导航、状态计数、对话框、离线安装、加载与空状态；保留真实状态刷新、宿主 API 和审批流程。
- 引入 shadcn/ui Radix 源码组件，保留 Tailwind 3 和 React 18。新增依赖仅在前端运行，无 Rust、Tauri 权限或跨进程协议变更。
- 右上角增加太阳/月亮/显示器三种外观选择，默认跟随系统，保存偏好；启动脚本提前应用主题，支持系统主题及窗口间偏好变化。
- 宿主原有固定深色颜色迁移到语义变量，插件 Shadow DOM 继承配色。强调按钮使用独立前景，保证浅色模式可读性。
- SSH 与串口 Shell 原地更新 xterm 背景、文字、光标、选区及 ANSI 颜色；本地搜索高亮同步。UART 发送框与接收区跟随主题，不改变人工发送方式或 MCP 命令队列。
- 注销终端颜色与搜索主题观察器，避免卸载后更新；相同调色板不重复刷新渲染器。

## 验收范围

宿主及两种插件前端生产构建、前端回归测试与真实浏览器视觉检查。浏览器覆盖两种配色、主题偏好恢复、跟随系统、1280/1024/768 布局、SSH/串口终端身份与输出保留、无额外订阅或发送，以及原有复制、粘贴、搜索、UART 和审批流程。

测试使用真实前端 bundle 与宿主契约替身，未把它记为远程 SSH、物理串口或 macOS/Linux 原生验收。详细规则见[桌面界面与主题](../architecture/desktop-appearance.md)。
