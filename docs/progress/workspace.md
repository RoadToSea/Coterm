# 工作区与桌面侧栏进度

## 当前能力

- 顶部保留应用标识、语言和主题切换；移除当前会话名称、MCP 按钮和重复的实例面板切换按钮。实例栏保留收起入口，收起后插件栏提供展开入口；插件栏去掉文字标题。
- 具名工作区可创建、删除，至少保留一组。分组数量最多 32 个，名称最多 64 个字符且不允许同名。新实例归入当前分组。
- 运行实例、待恢复实例均支持拖放移动；实例工具中的下拉框支持键盘移动。删除分组将成员移至剩余第一组，操作本身不关闭连接、不改变实例/会话 ID。
- 实例和恢复记录使用圆角卡片；实例图标与插件栏一致，更多和删除按钮在卡片右侧横排，悬停和键盘焦点进入时显示。
- DPAPI 文件兼容旧版缺省分组字段。只持久化最近一次实际使用的实例批次，空启动保留上一批；删除最后一个本批实例不复活旧记录。上一批未恢复的项本次仍可从内存恢复。

## 2026-10-30：人工使用反馈

- 所有反馈项已落地；跨组件交互提取至 `WorkspaceInstances`，分组归属由桌面专用命令持久化，插件协议、MCP 和审批规则保持原有边界。
- Windows 主窗口关闭原生拖放拦截，允许 HTML5 内部拖动；外部文件拖入不触发默认导航。平台依据来自当前安装的 Tauri CLI `config.schema.json` 对 `dragDropEnabled` 的说明。
- 前端 `pnpm build` 与完整 `pnpm test` 通过：54 项，无跳过。浏览器验证真实桌面与 SSH 前端，覆盖分组创建/删除/取消、两类卡片拖放、菜单移动、移动失败保留归属、悬停/键盘动作、恢复/销毁、翻译和连接/订阅保持。
- `cargo check --workspace --locked`、桌面全部 11 项测试及桌面 Clippy 通过；其中工作区 7 项包含旧加密文件迁移、配置隔离、分组限制、移动、失败回滚和多轮启动批次。修改的工作区 Rust 文件通过 rustfmt。

## 限制与继续入口

- 旧数据未记录启动批次，升级时无法准确区分旧恢复项的历史来源；新版首次创建/恢复实例后，后续启动按最近批次收敛，不自动猜测删除旧配置。
- 工作区分组的临时展开状态不单独持久化；实例栏整体折叠、分组归属与选中分组会保存。非 Windows 继续只保留会话内工作区；macOS/Linux 原生 WebView 拖放仍需真机复测。
- 本轮验证不连接真实 SSH 或物理串口，也不修改用户的实际工作区文件。
