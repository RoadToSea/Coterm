## 基座完成度（不含插件）

**核心闭环可用，基座尚未全部完成。** 已固定的是后端控制协议 v1.0，前端 SDK 与运行时扩展仍有缺口。串口实现质量、SSH 扩展功能和本地 PTY 不计入基座完成度。

建议首版目标为 **Windows 上运行可信本地插件**，按以下顺序收尾：

| 顺序 | 范围 | 当前缺口与完成要求 |
|---|---|---|
| 1 | 前端 SDK 与公共交互 | SDK 尚未冻结；`requestText/requestSelection` 未接通，确认交互使用浏览器弹窗。补齐公共交互，明确支持范围与版本策略。 |
| 2 | 状态保存与恢复 | 工作区、实例配置引用与布局尚无完整保存/恢复流程；操作账本仅在内存中。明确宿主历史保留策略，插件业务数据仍由插件负责。 |
| 3 | 生命周期可靠性 | 已有断线后操作标为 `unknown` 的处理；继续补齐崩溃后的实例状态收敛、重新启动和恢复流程，不能自动重放写操作。 |

有界 JSON 事件已接通；`subscribeStream`、二进制流/StreamRouter 与窗口信用尚未实现。通用流、多轮交互、完整 MCP 能力、插件签名与市场可明确列为后续范围，不必全部完成才交付上述首版。

## 优先待办

### P0：插件可靠性

- **串口资源回收**：读取线程缺少停止信号与 join；同步打开端口仍占用异步任务，外层 timeout 不能中断阻塞打开。补断开、销毁、停止和重连测试。
- **串口输入脱敏**：`serial.write` 当前未标记敏感输入，人工输入可能包含密码；需补账本脱敏与验证。
- **Unix 串口支持**：端口校验拒绝 `/dev/...`，与 manifest 声明的平台不一致；补设备路径、大小写/别名、权限与系统依赖验证。

### P1：运行时与交付

- 基座首版按上表收尾；继续补插件模板、独立语言实现验证与 manifest 扩展规则。
- 扩展流接口时，用持续订阅型测试插件验证窗口信用、背压、取消与数据缺口。
- 跨平台发布另补 CI、安装包和系统依赖验证；核验 macOS 图标，当前 `icon.icns` 仅 8 字节。
- 插件验收另覆盖远程 SSH 和物理串口，不与基座验收混算。

### P2：功能与生态

- 本地 PTY、SSH 密钥/MFA/SFTP/转发、串口流控/热插拔、MQTT/CAN/Modbus。
- 命令块选择到 MCP 上下文的闭环；Resources、Prompts、订阅、进度和协议级取消。
- 插件签名、权限与前端隔离、秘密物理通道、安装更新、回滚和市场。
