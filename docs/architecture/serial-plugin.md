## 基座与插件的边界

- 基座负责插件生命周期、实例路由、前端挂载、来源识别、审批、公共交互、操作记录和 MCP Bridge。
- Serial 插件负责串口配置与连接、文本和 HEX 收发、控制线、输出缓冲及命令队列；具体设备协议由独立插件实现。
- 前端仅通过基座 API 调用插件；实例级调用由宿主绑定实例，MCP 对外使用公共实例名称，UUID 只在内部路由。
- 插件单独注册 MCP descriptor 和内部操作映射，不能因业务操作存在就自动向 Agent 开放。串口人工单次写入和控制线接口不注册为 MCP 工具。
- Agent 提交经过宿主审批，Bypass 或放行只跳过提交审批；秘密交互、协议认证和交付不确定性仍按运行时规则处理。

## 串口界面

新建实例通过插件级只读操作 `serial.plugin_info` 获取本机 `ports`，不依赖已有实例。基座在配置页调用前启动插件并完成握手；每次点击或键盘展开端口下拉框时重新枚举，保留仍存在的选择，不再提供独立刷新按钮。在途查询合并重复触发；支持原生 `showPicker` 的宿主读取新列表后再展开，避免弹出的菜单保留旧快照。只有成功返回空数组时显示「未检测到串口」；启动 / 查询失败、旧后端缺失 `ports` 等情况显示错误，再次点击下拉框可重试，加载中或无有效端口时不能提交。此过程不打开串口、不修改 DTR / RTS，也不发送设备数据。

界面与配置由插件前端自行管理，设计见 [串口调试界面](../design/serial-console.md)。终端保留原始按键语义；UART 使用 Enter 单次发送、Shift+Enter 换行。配置平铺，在接收区上方展开，不改变接收区与发送栏尺寸。断开后可编辑本地通信草稿，在下次人工连接前通过 `serial.configure` 应用，成功后才调用 `serial.connect`；固定端口不显示为可修改项，不保留应用按钮或端口列表。顶栏连接按钮同时表示状态：连接时绿色，断开时灰色。

UART 接收 ASCII / HEX、暂停、清空和保存放在快捷栏。配置右侧点击调整快捷栏后，控件围绕自身中心小幅快速晃动，直接拖动排序并显示插入位置；拖动时接收区下方显示垃圾桶，投放后移除。原显隐复选框列表由紧凑提示、恢复默认和完成操作替代，移除后可单项加回。键盘可用 Alt + 左右方向键排序、Delete / Backspace 移除。调整期间抑制控件原业务动作，取消拖动不改变布局，关闭调整恢复正常操作；减少动画设置下禁用晃动。只将控件 ID 的顺序及显隐保存在既有 UI 偏好中，不清空接收数据或改变协议状态。发送 ASCII / HEX 使用分段滑块，切换时按 UTF-8 转换草稿；非法 HEX 或不能解码的二进制保持原稿并警告。定时发送用同一个按钮及绿色运行状态表达启停；发送历史使用回转时钟图标。

提示由插件前端直接引用 SDK 的 [非模态提示组件](../../packages/plugin-sdk/docs/toasts.md)，错误红色、警告黄色，自动消失，不抢焦点；不新增 `PluginAPI` 或 MCP 工具，也不引入宿主权限或跨进程消息类型。

接收换行补全由配置面板的「LF 补 CR」「CR 补 LF」两个独立复选框控制，可同时勾选，默认均不选。分别将单独 LF、CR 补成 CRLF，已存在的 CRLF（包括跨事件拆分的 CR / LF）不重复补全。该功能只作用于终端和 UART 文本显示；终端对后续输出生效，UART 文本从有界原始缓存重新渲染。HEX、保存文件、收发计数、后端缓冲与 MCP 输出保持原样。偏好按实例保存在前端本地存储，不调用 `serial.configure`；清空、连接更换和回放缺口均重置转换状态。

文件导入使用用户选择的浏览器 File，接收保存是有界缓冲的快照下载，不开放任意路径文件代理。发送历史只驻留当前挂载内存；定时发送等待上次完成再计时，停止后不恢复旧队列。实现进度与限制见 [Serial 进度](../../plugins/plugin-serial/docs/progress.md)。
