# 模块职责与信息交互

本文件定义交接语义与数据所有权，不规定调用语言、函数或编码。每个模块完成自己负责的验证和收敛，不通过重复转发增加层级。

## 数据所有权

| 信息 | 负责解释与更新 | 保存寿命／允许的读取方 |
|---|---|---|
| 保存项、分组、布局 | 工作区与配置 | 跨启动；桌面读元数据，驱动只接收自己的连接配置 |
| 连接配置 | 驱动校验含义，工作区安全保存 | 跨启动；不在普通实例列表泄露完整配置 |
| 规则组与绑定 | 审批定义，工作区负责可靠保存 | 跨启动；人工设置可编辑，Agent 不可修改 |
| 实例 Bypass | 实例审批持有，工作区按保存身份保存 | 已保存实例跨启动；临时实例仅内存 |
| 实例运行身份、操作状态 | 实例运行 | 本次运行；桌面、Agent 按目标授权查询 |
| 连接状态、接收正文、命令归属 | 对应驱动 | 当前有界会话；实例查询与前端显示 |
| 审批完整草稿 | 宿主待审批内存 | 仅待决期间供人工查看编辑；公共账本只保留脱敏摘要 |
| 原始秘密与用途引用 | 受控交互及目标驱动 | 短期一次性；普通记录、Agent 和广播不可读取 |
| 选区 | 人工视图更新，驱动验证连接后保留 | 当前连接；Agent 可读取，不能写入 |
| 显示偏好与显示副本 | 桌面交互 | 偏好按保存范围持久化，正文副本不持久化 |

“数据记录与读取”统一的是责任和查询语义，不是要求后端再复制一套所有协议数据。

## 模块交接表

| 发起方 → 接收方 | 交付信息 | 返回／后续信息 | 失败与限制 |
|---|---|---|---|
| 桌面 → 工作区 | 名称、分组、连接配置、保存身份 | 保存结果或待恢复目录 | 失败保留原值，配置不混入界面布局 |
| 工作区 → 实例运行 | 驱动种类、连接配置、用户名称 | 新运行实例身份 | 只创建不连接；恢复失败保留恢复入口 |
| 工作区 → 审批 | 组引用、已保存实例的 Bypass | 当前实例策略已生效 | 保存和发布成功后才提示完成 |
| 桌面／Agent 接入 → 实例运行 | 操作名、业务参数、已绑定目标、等待意愿 | 稳定操作身份及状态 | 来源由入口确定，调用方不自报权限 |
| 实例运行 → 审批 | 已验证来源、登记的操作效果、命令字段和目标 | 要求审批或允许继续 | 未声明可匹配文本时不能靠命令规则豁免 |
| 实例运行 → 驱动 | 操作身份、当前实例、执行或仅准备、业务参数 | 结果、待审批草稿、待交互或异步受理 | 准备阶段无副作用；批准时复核连接和参数 |
| 审批界面 → 实例运行 | 提案身份、目标和本次批准的参数快照 | 拒绝、执行状态或过期错误 | 不从当前编辑器重新偷换已批准参数 |
| 驱动 → 交互 → 桌面 | 目标、用途、提示、期限和操作关联 | 用户响应或取消 | 普通通知只带显示信息，不带原始秘密 |
| 受控交互 → 驱动 | 绑定目标和用途的短期秘密及响应关联 | 原操作恢复或认证错误 | 迟到、跨实例、已消费或过期响应拒绝 |
| 驱动 → 数据记录／实例运行 | 连接身份、原始接收、命令边界、完成事实 | 有界历史和操作终态 | 领域正文归驱动，公共账本脱敏 |
| 驱动／实例运行 → 桌面 | 状态变化、输出通知、数据缺口、待处理版本 | 按目标补读快照、确认消费 | 通知不保证无限历史；卸载不销毁实例 |
| Agent 接入 → 后端读取 | 目标、行数／对话数／操作身份 | 有界快照、状态、截断与缺口 | 无游标；指定对象不存在不回退其他数据 |

## 交接信息的最小内容

| 信息 | 必须知道的内容 | 不应包含 |
|---|---|---|
| 创建／恢复请求 | 保存身份、驱动、配置、显示名 | 已连接标志、历史命令重放 |
| 操作上下文 | 操作身份、可信来源、目标、效果、参数 | 调用方覆盖来源或效果的声明 |
| 审批提案 | 操作与提案身份、目标、完整可编辑草稿 | 任何已经开始执行的暗示 |
| 操作收据 | 操作身份、提案关联、状态、等待是否结束、可用结果与错误 | 通过超时猜测的完成结论 |
| 连接事件 | 所属实例、当前连接身份、状态或数据位置 | 其他实例数据、秘密 |
| 命令结果 | 输入、普通输出、错误输出、执行方式、流是否合并、状态、完成证据、截断及错误 | 未知时虚构的退出码 |
| 待处理快照 | 单调版本、全部待审批与交互的稳定身份和显示信息 | 秘密原文、普通通知中的完整操作参数 |

公共错误包含类别、稳定错误标识、可读说明和非秘密详情。领域错误由驱动描述，运行模块不能通过字符串内容猜测已发送或未发送。

## 主要数据流

### 创建、保存、恢复

1. 驱动配置界面校验连接参数；桌面单独处理名称和分组。
2. 工作区协调创建与保存，分配保存身份和新的运行身份。
3. 审批加载当前组引用与自身 Bypass；保存成功后对新提交生效。
4. 用户显式连接；恢复只走创建，不恢复旧连接或未执行请求。

### Agent 写入与审批

1. Agent 接入按名称选择实例，运行模块校验归属、来源、能力和参数。
2. 实例审批收到验证后的上下文；需要人工审批时只准备草稿，返回原操作收据。
3. 用户可编辑并批准；运行模块用已确认快照再次校验，驱动复核当前连接。
4. 实际执行后更新记录和状态；拒绝、取消或目标失效则不提交。旧提案不因策略放宽自动执行。

### 接收、呈现与查询

1. 驱动取得真实接收字节，保存有界历史并识别本协议能够确认的边界。
2. 推送连接内输出或轻量失效通知，前端维护自己的显示副本。
3. 前端先安装监听再读快照；缺口时补取仍在后端的数据，不把重复通知再显示一次。
4. Agent 直接读后端最近行、选区或对话，保留未知、截断和淘汰标记。

### 认证与其他交互

1. 驱动说明本次操作需要何种用户响应，暂存有界上下文并释放控制等待。
2. 桌面从宿主待处理快照展示交互，秘密只经专用路径交给指定用途。
3. 响应关联原交互并恢复原操作；取消、过期、销毁或连接变化后拒绝响应。

### 断线与退出

1. 驱动报告连接停止并停止旧输入，不因剩余队列或迟到事件重新发送。
2. 实例运行收敛提案、交互和操作；已派发且无确认的结果为未知。
3. 桌面清理对应显示订阅；工作区保留允许恢复的配置，不保存执行现场。
4. 应用退出有界等待连接和作业回收；不能确认资源终止时不宣称已经完全结束。

## 交互验收

- 两个同驱动实例同时操作，一个更新配置、审批或断线不影响另一个。
- 修改共享规则组后，所有绑定实例的新提交使用新规则，旧待决提案不动。
- 审批后连接已变化时拒绝执行；旧终端事件、旧选区、旧密码响应同样失效。
- 视图关闭后 Agent 仍能读后端；重开不会重复发送或创建连接。
- 慢消费明确报告缺口，历史淘汰与原始接收缺失可以分别定位。
