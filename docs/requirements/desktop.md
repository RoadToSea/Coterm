# 桌面交互需求

## 职责

向用户呈现连接、终端、设备数据、审批和设置；从后端状态取得事实。配置字段和协议特有操作由对应驱动的界面负责，公共交互保持一致。

| 编号 | 要求 | 验收条件 |
|---|---|---|
| UI-01 | 工作区分组、实例管理和内容标签职责分开 | 分组移动不重连；关闭标签不销毁实例；销毁需要确认 |
| UI-02 | 创建配置内联展示，自定义名称独立于连接参数 | 名称与标签页及 MCP 一致；重名时名称框红边并提示“已存在同名实例”，提交阶段的重名错误也回到该字段；不要求填写内部操作名 |
| UI-03 | 切换标签只隐藏现有面板，保留会话 | 关闭面板释放显示资源，重开从后端恢复可用内容 |
| UI-04 | 连接按钮使用后端真实状态 | 断线、重连、错误和状态不可用可区分，不把实例可用当已连接 |
| UI-05 | 终端块只使用上下横向分割线 | 去掉左右竖线和行号栏竖线；纯数字块号与正文对齐 |
| UI-06 | 块选择与文本选区分别处理 | 点击块号可多选，正文可正常拖选复制；取消全选不终止命令 |
| UI-07 | 后台结果独立查看，不打断前台 | 关闭详情不终止作业；查看历史时不被新任务强行覆盖 |
| UI-08 | 终端与字节调试按同一实例切换 | 不重新创建实例；切换失败显示原因，不伪造能力变化 |
| UI-09 | 语言、主题、字号改变只影响显示 | 保留连接、终端和订阅；隐藏面板重新可见时尺寸正确 |
| UI-10 | 错误与警告有界、可访问且不抢焦点 | 普通提示自动消失；审批和认证使用正式交互，不藏在短暂提示中 |
| UI-11 | 异步请求与订阅随视图正确清理 | 卸载后迟到响应不修改新视图，定时发送停止 |

## 终端公共操作

| 操作 | 要求 |
|---|---|
| 复制 | 有选区时 Ctrl+C 复制，无选区才发送中断；复制失败不回退成远端中断 |
| 专用复制／粘贴 | 支持常用系统组合键；粘贴按终端语义发送一次，不为读取剪贴板增加系统权限 |
| 搜索 | 只查当前终端缓冲，纯文本、不执行命令；支持前后跳转、计数和退出 |
| 全选与 Esc | 本地全选不发送控制字符；Esc 优先退出搜索或清选区，其余保留终端语义 |
| Shell 控制键 | 保留行编辑、历史、清屏和中断等终端语义，不绑定页面行为 |
| 输入法与其他输入框 | 不在组合输入时误发；配置、审批编辑器和 UART 发送框保留自身行为 |
| 退格 | 串口默认 BS、网络按配置；只映射普通物理退格，不改粘贴内容 |

## 字节调试

- 接收区支持文本／HEX、时间戳、自动滚动、暂停显示、清空显示和保存当前有界快照。
- 暂停显示不暂停设备读取；清空显示和更改换行不得伪造后端设备数据。
- 发送支持文本／HEX、显式行尾、输入历史和定时发送；Enter 发送、Shift+Enter 换行，输入法确认不发送。
- 导入用户选择的文件只填入草稿，用户发送才产生通信；导出只保存有界快照，不开放任意文件路径。
- 定时发送等待上一轮完成再计时；改稿、模式变化、断线、失败、关闭视图后停止，不跨启动恢复。
- 工具栏可排序、隐藏和恢复，提供键盘替代；调整期间不触发控件业务动作，遵循减少动画设置。
- LF 补 CR、CR 补 LF 仅影响显示，已有完整换行不重复补全，包括跨事件分包。

## 设置与审批

提供通用、外观、终端、审批和 MCP 设置，中英文可搜索。显示偏好即时生效；连接、审批和 MCP 配置按各自明确的保存规则生效，不能以统一“自动保存”掩盖不同语义。

审批组管理、实例分配和 Bypass 需求见[审批与交互](approval.md)；跨启动保存范围见[工作区与配置](workspace.md)。窄窗口、键盘焦点、滚动底部和终端光标必须可用，不能因布局把最后一行裁掉。
