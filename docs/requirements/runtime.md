# 实例运行需求

## 职责

管理运行实例身份、操作路由、状态流转和退出收敛。连接是否认证、命令是否完成由驱动提供事实；运行模块不从界面颜色或输出文本猜测结果。

| 编号 | 要求 | 验收条件 |
|---|---|---|
| RT-01 | 每种驱动支持多个相互隔离的实例 | 路由、审批、连接、数据和取消仅影响指定目标 |
| RT-02 | 创建与连接分离 | 创建、恢复、挂载和切换视图均不自动连接或启动 Shell |
| RT-03 | 驱动运行、实例可用、连接成功分别报告 | 实例可用但尚未连接时，查询不会显示为已认证 |
| RT-04 | 提交前验证来源、目标、能力和参数 | 目标失效、能力不支持或参数错误时，执行前明确拒绝 |
| RT-05 | 每次提交获得稳定操作身份 | 审批、执行、查询和取消始终关联同一操作 |
| RT-06 | 审批准备不产生执行副作用 | 等待审批期间不连接、不发命令、不修改设备 |
| RT-07 | 长操作允许异步完成，不阻塞其他实例的控制 | 调用方可先拿收据，再查询原操作 |
| RT-08 | 等待超时与执行取消分别处理 | 调用方结束等待不重放操作、不换执行模式、不自行宣布失败或成功 |
| RT-09 | 取消返回实际可确认的结果 | 区分未提交、已停止、不支持和未知；不能把已发送字节撤回 |
| RT-10 | 销毁、停止、退出收敛资源和待处理状态 | 清理输入队列、连接、作业、审批、交互、订阅；迟到结果不能复活实例 |
| RT-11 | 控制、通知、历史和并发均有容量上限 | 满载时拒绝、报告缺口或关闭故障任务，不无限排队 |
| RT-12 | 驱动任务故障的影响范围可解释 | 该驱动实例收敛为失败；不能把任务隔离描述为进程崩溃隔离 |

## 操作状态

一次操作可以经历受理、等待审批、已派发、运行和终态。终态包含已完成、失败、拒绝、取消以及结果未知。领域命令的退出码与宿主操作终态分开：成功收到“命令已执行且退出码非零”的结果，不等于没有收到操作结果。

操作可能尚未派发就被取消，也可能已向设备发送后无法确认。网络断开、驱动故障和等待超时都不能单独证明未执行。

## 生命周期边界

- 重连、重启 Shell 或恢复保存项后，旧连接输入、选区、审批提案不能作用于新会话。
- 关闭视图仅释放显示资源；销毁实例才回收后端实例资源。
- 停止驱动保留配置恢复入口，旧运行实例不能被重新路由到新任务。
- 退出采用有界等待；底层阻塞调用或外部子进程不能被确认停止时，不宣称强制回收已经成功。

公共要求见[身份、异步操作和有界数据](common.md)；交接信息见[模块交互](interactions.md)。
