# Design

本目录记录复杂业务实现前的方案、取舍、接口草案和验收条件。方案落地后，将有效契约归入 `architecture/`，实施与验收结果归入对应模块的 `progress/`；重复或被替代的方案删除，历史由 Git 保留。

当前保留的 [终端聚焦与内置驱动架构决策](terminal-focus-and-in-tree-architecture.md) 说明产品边界、关键取舍与主要数据链路。稳定接口以 [SPEC](../SPEC.md) 和 `architecture/` 为准，后续工作见 [项目进度](../progress/project.md)。

[审批规则组与实例分配](approval-rule-groups.md) 记录规则组独立保存、实例引用和审批管理界面的设计草案。
