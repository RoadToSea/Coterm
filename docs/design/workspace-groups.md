# 工作区分组与最近一次恢复快照

## 问题与边界

人工使用反馈要求移除重复工具栏入口，补齐工作区增删和实例拖动，并避免恢复记录跨多次启动不断累积。工作区是基座管理连接实例的分组；它不更改 SSH、串口等插件的配置或业务模型。

## 方案与取舍

- 在现有 DPAPI 加密工作区中增加具名分组、保存项归属和当前分组，不引入新的数据库、插件消息或依赖。旧文件通过默认字段迁入默认工作区。
- 创建实例时显式携带当前分组；拖放与菜单移动使用稳定配置引用，运行实例和待恢复实例均可移动，不重建运行连接。
- 删除分组只移动成员，不批量销毁连接；操作前确认目标分组。至少保留一组，避免实例落入不存在的分组。
- Windows WebView2 必须关闭 Tauri 原生拖放处理，才能把 HTML5 拖放事件交给前端。窗口阻止外部文件拖放的默认导航，离线安装继续使用原有专用入口。
- 只落盘本次实际使用的实例，避免历史恢复项按启动次数累积。上一批记录在本次内存中仍可恢复；仅查看而未使用实例时继续保留上一批，写入失败不提前替换恢复快照。旧格式没有批次信息，不能可靠倒推出哪个历史项来自最后一次启动。
- 新增分组限定 32 个、名称 64 个字符；沿用 128 个保存项、512 KiB 编码与原子写入上限。非 Windows 沿用会话内工作区，不落盘明文。

## 验收与落点

- 顶栏不再包含当前实例名称、MCP 或重复的实例栏折叠按钮；侧栏折叠后仍可用鼠标和键盘恢复。
- 分组可创建、删除；运行和待恢复卡片均可拖放，菜单提供键盘替代。删除分组和移动均不增加插件连接、创建、销毁或订阅调用。
- 恢复卡片为圆角；实例卡片的更多和删除按钮右侧横排，悬停及键盘焦点可见；图标与插件栏一致。
- 验证旧文件迁移、加密配置不泄漏、名称与容量限制、最新批次落盘、空启动保留快照、最后一个实例删除和写入失败回滚。
