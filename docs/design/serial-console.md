# 串口调试界面

## 使用反馈后的交互调整

- 顶栏只保留模式、连接、配置和快捷栏设置；连接按钮直接表达状态，断开为灰色、连接为绿色。
- 配置平铺，不再分通信 / 接收 / 发送，不显示固定端口和端口列表，也不保留应用按钮。断开时编辑通信参数，下次连接前校验并应用；连接时尝试修改不可变参数给出短暂警告。
- 接收 ASCII / HEX 与保存按钮放到快捷栏，文件名仍在配置中填写。打开快捷栏设置后，直接拖动实际控件左右排序，显示插入位置；设置面板位于快捷栏下方，只保留显隐和恢复默认。支持 Alt + 左右方向键调整已聚焦控件，布局偏好不包含通信内容。
- 发送区删除单次发送按钮，保留 Enter / Shift+Enter；ASCII / HEX 使用分段滑块，切换时转换草稿，HEX 以空格分隔字节，非法输入给出警告。
- 定时发送仅显示间隔、ms 和状态按钮；未发送为灰色、发送中为绿色。暂停 / 清空采用带可访问名称的图标。
- 提示使用 SDK 的公共非模态组件，错误用红色、警告用黄色，默认自动消失；不抢焦点，悬停或聚焦时允许阅读，数量有界且相同消息去重。

保存仍采用当前缓冲快照下载，文件位置遵循宿主下载设置；本轮不扩展任意路径文件代理。

## 布局与交互

- 顶栏左侧切换终端 / UART，右侧连接与配置；接收区占据剩余空间。
- UART 底部保留多行输入、文件导入、发送历史、ASCII / HEX、毫秒间隔和定时发送。Enter 单次发送，Shift+Enter 换行；输入法组合期间 Enter 不发送。
- 发送历史使用回转时钟图标，与文件导入图标区分；保留提示文字和可访问名称。
- 配置在顶栏下方向下展开，覆盖接收区，不改变接收区和发送栏的尺寸。Esc 或再次点击配置收起；配置内容过长时独立滚动。
- 配置平铺显示波特率、数据位、停止位、校验、DTR / RTS、行结束符及接收文件名。通信参数草稿在用户下次连接时应用；已连接时 DTR / RTS 复选框实时调整电平，其余通信参数只读并通过公共提示解释原因。DTR / RTS 是控制线电平，不冒充 RTS/CTS 自动流控。

## 数据与安全边界

- 人工发送继续调用 `serial.write` / `serial.write_hex`，不使用 MCP 命令列表。单次最多 16 KiB（包含行结束符）。
- 文件由用户通过浏览器文件选择器授权，只导入发送框，确认后才发送；ASCII 按 UTF-8 文本读取，HEX 模式导入原始字节。
- 发送历史仅保留当前挂载内最近 50 项、最多 64 KiB，不写磁盘；重复发送记录一次，失败不录入。
- 定时发送默认 100 ms，范围 20–60000 ms；单次完成后再计时，不积压；断线、切换模式、改输入或卸载即停止。
- 接收导出保存当前有界缓冲的快照，文件名可编辑。它不是持续落盘日志，也不提供任意路径读写；浏览器下载位置由宿主 WebView / 系统决定。
- 不新增宿主权限或跨进程消息类型；新增串口领域操作需更新插件接口文档和契约测试。

## 验收

真实插件构建的浏览器用例覆盖 Enter、Shift+Enter、IME、配置覆盖与焦点、窄窗口、收发模式、文件导入、历史、重复发送停止与卸载。串口配置在无硬件契约测试中验证；物理收发仍需设备验收。
