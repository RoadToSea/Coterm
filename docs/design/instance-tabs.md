# 实例标签页与内联连接配置

## 目标与边界

- 点击插件在主工作区显示插件自己的通信配置表单；不再弹出新建窗口，不向普通用户展示操作调用器或原始 JSON。
- 侧栏管理工作区分组、实例生命周期和恢复入口；主区域上方的标签页负责已打开实例的切换。
- 基座不理解 SSH/UART 配置字段，继续调用插件 `configure(container, api)`。无配置前端的插件显示说明，不提供 JSON 后门。
- 不改变 MCP、审批、认证、插件协议或配置存储，不新增依赖。

## 视图生命周期

- 首次加载打开现有运行实例；新建、恢复和点击侧栏会打开并选中对应标签。后台新出现的实例可从侧栏打开。
- 切换标签或进入配置页只隐藏其他面板，保留前端、终端输出、任务选择和订阅；真正关闭标签才卸载该前端。
- 标签的关闭仅关闭视图，不销毁后端实例或删除保存配置；侧栏可重新打开。销毁实例仍需确认，并清理对应标签。
- 运行状态轮询清理已移除的实例视图，失败实例显示恢复入口且卸载旧前端。关闭当前标签选择相邻标签；关闭最后一个显示空状态，刷新不重新打开已关闭标签。
- 标签页支持方向键、Home/End、Delete 和明确的关闭按钮；窄窗口横向滚动，选中项自动进入可见范围。
- 标签打开状态暂不跨启动持久化，沿用已有活跃实例/工作区布局保存机制。

## 验收

真实宿主与真实 SSH/串口前端在浏览器内验证：内联创建和失败重试、无调试控件、圆角配置控件、多标签切换不重连/不重订阅、关闭/重开/销毁、轮询清理、键盘导航、窄屏溢出、中英文和审批回归。宿主替身只模拟后端契约，不代替原生 WebView 与实际通信验收。
