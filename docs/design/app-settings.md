# 应用设置

## 入口与布局

原顶部语言选择器替换为带齿轮图标的“设置”按钮。主题快捷切换保留，设置内同时提供外观选项，两处共享状态。设置使用现有原生 dialog 公共组件，打开聚焦搜索，Esc / 关闭按钮退出并恢复入口焦点；显示设置不卸载实例视图。

左侧按“全部设置、通用、外观、终端、MCP”分类，右侧显示设置项、说明与控件。窄窗口将分类改为可横向滚动的导航，设置正文独立滚动；右侧 MCP 分类标题处显示「MCP 状态」与「已启动 / 未启动」，不在搜索框上方占用整行；没有 MCP 搜索结果或切到其他分类时隐藏；底部显示生效方式及字体 / 光标重置入口。

## 首批设置

| 分类 | 设置 | 范围 / 默认 |
|---|---|---|
| 通用 | 语言 | 简体中文 / English；兼容已有语言偏好 |
| 外观 | 配色主题 | 浅色 / 深色 / 跟随系统；保留已有主题偏好 |
| 外观 | 界面字号 | 12–20 px，默认 14；同步缩放界面文字及 rem 控件 |
| 终端 | 终端字号 | 10–28 px，默认 13；SSH、串口 Shell、UART 接收及命令输出 |
| 终端 | 终端行高 | 1.0–2.0，默认 1.0；终端渲染器 |
| 终端 | 光标闪烁 | 默认开启；终端渲染器 |
| MCP | 本机 Bridge 端口 | 1–65535，默认 51234；只保留输入与显式保存，按设备持久化 |
| MCP | MCP 连接 | 自启动 / 手动启动，各占一半的单选胶囊；默认自启动；手动模式显示启动 / 关闭按钮 |
| MCP | 客户端配置 | 连接项下方独立一行，左侧标签，右侧“查看配置”按钮；弹窗查看并复制 |

提供实时字号预览。显示偏好每次修改立即生效；MCP 端口点击保存后生效。“重置字体与光标”只恢复显示偏好，语言、主题、MCP 端口与启动方式保持用户选择。

## 搜索

搜索覆盖全部分类，不受当前分类限制。按空白拆分关键词，所有词均须命中；匹配中英文名称、说明、分类和常用别名，例如 font / 字体 / 字号 / cursor / 光标。结果保留分类标题并显示数量；无结果时给出清除搜索入口。点击分类会清除搜索，回到该分类。

## 状态与边界

- 语言和主题沿用 `coterm.locale`、`coterm.theme`；新增 `coterm.preferences.v1` 仅存界面字号、终端字号 / 行高和光标闪烁。
- 启动校验字段类型与范围，未知字段不保存；损坏记录回退默认。存储不可用时当前会话仍可调整，其他窗口的 `storage` 通知同步显示偏好。
- CSS 变量跨 Shadow DOM 继承；SDK 的终端偏好辅助函数原地更新 xterm 并重新适配尺寸，卸载必须注销观察器。插件可独立接入，不强迫无 UI 或第三方插件实现公共业务模型。
- 显示偏好不新增后端命令或 MCP 操作，不主动连接 / 断开或发送命令。字号变化引起的 SSH PTY 尺寸同步仍走原有 resize 接口。
- MCP 端口通过专用宿主命令保存，范围由前后端共同校验；启用状态下安全换端口，失败保留旧服务，停用时不隐式启用。新端口只在 IPv4 回环监听；客户端配置同步 `--addr`，换端口后客户端需要复制更新后的配置并重连；普通设置项不显示重复说明和桥接地址。设置文件与显示偏好独立，不保存到浏览器显示偏好中。契约见 [MCP 接入](../architecture/mcp-integration.md#端口设置与宿主接口)。未新增依赖、Tauri 权限或插件运行时消息。

- 连接模式与端口共用设备本地设置，默认随 Coterm 自启动；旧端口文件兼容。选择自启动立即启动，选择手动保留当前运行状态并显示开关，下次启动 Coterm 保持关闭。绑定或保存失败保留旧模式和监听。分类标题状态以后端成功返回为准，读取/操作失败显示可恢复错误；相关控件共用快照和操作锁，不各自重复读取，不修改插件连接或 Agent 审批规则。手动启停移到连接项，客户端配置弹窗只负责配置查看与复制。

## 验收

真实宿主和插件 bundle 的浏览器测试覆盖分类、中英文搜索、无结果、实时字号、主题入口同步、语言切换、持久化、重置、跨窗口同步、损坏数据恢复、Esc / 焦点与窄窗口。检查终端 DOM 身份、订阅次数及连接 / 写入调用不变。另用纯函数测试验证类型、范围、存储失败和注销。MCP 验证等宽圆角胶囊、重复点击不取消选择、启动失败和写盘失败、单一并发操作、分类标题状态和独立客户端配置行、手动模式重启关闭、自启动恢复、旧文件迁移、端口与模式互相保留。整体规则同步到 [桌面外观](../architecture/desktop-appearance.md)，进度维护于 [工作区与桌面](../progress/workspace.md)。
