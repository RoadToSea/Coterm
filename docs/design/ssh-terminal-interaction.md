# SSH 终端交互与块选择

状态：2026-11-02 已实施并通过本机定向验证；实现能力以 [SSH 架构](../architecture/ssh-plugin.md) 与 [SSH 进度](../progress/ssh-plugin.md) 为准。

## 执行边界与来源标签

- 保持 `ssh.command` 的共享 PTY 语义与 `ssh.exec` 的独立执行语义，不合并接口，不将 exec 改为向人工 Shell 输入。
- 主终端中的来源标签直接显示在命令前，如 `[🤖 Agent] ls -la`、`[👤 Human] pwd`，不放在独立块标题中。
- Agent 使用青蓝色，Human 使用薄荷绿，标签包含文字，不能仅靠颜色区分。
- 标签属于前端展示，不作为命令内容发送给远端；来源沿用宿主的可信来源，不根据命令文本推测。

## 同屏命令块与选择

- 主终端内同时显示命令、回复和左侧块号；移除互斥的 Terminal / Command blocks Tab。
- 人工直接在主终端输入，使用现有共享 PTY；不再提供底部「共享终端命令」输入栏与执行按钮。原始按键不据此自动生成命令块，可信块边界继续由插件后端提供。
- 优先采用终端行标记和 decoration 实现可点击块号、块边界与选中高亮。需要处理换行、滚动、缓冲淘汰及卸载生命周期；不能仅凭 API 存在就视为完成。
- 点击块号切换选择，允许多选；正常终端输入与正文文本选择保持可用。
- 块选择只用于把所选命令及对应回复作为上下文传给 Agent，不代表执行或取消命令。
- 行号栏顶部只放一个红色圆形叉号按钮，采用 macOS 关闭控件的紧凑外观，tooltip 和可访问名称为「取消全选」；空选择时禁用，保留红色辨识。点击只清空选择，不关闭终端。
- 行号栏根据当前有效 PTY 块号的最大字符数自适应宽度，最小 28px；编号增长、淘汰与重连后同步伸缩，不保留固定大空白。
- 选择与上下文按实例隔离，使用实际块 ID；沿用有界数据、截断和缺口提示，不因选择而无限保留输出，不包含秘密。
- 现有消息块与向 Agent 传递上下文的实现限制见 [SSH 进度](../progress/ssh-plugin.md#限制与下次入口)。本次确认不代表传递链路已接通。

## Exec 面板与任务胶囊

- 支持右侧或底部停靠，拖拽分隔条调整尺寸；任务胶囊保留单行紧凑展示，点击查看详情。
- 面板打开且处于跟随最新状态时，新任务自动成为当前展示任务并显示流式日志。
- 面板关闭时，新任务只更新胶囊，不自动展开面板，不抢焦点。
- 点击历史任务暂停跟随，并显示正在查看的任务及「恢复跟随最新」入口。
- 点击最新任务、点击恢复入口，或在 Exec 面板内按 `Esc`，恢复跟随最新。
- 胶囊使用细边框、顶部高光、小圆点状态灯及轻量点击反馈；适配明暗主题并遵循减少动态效果设置。状态同时提供可访问的文字含义。

## 焦点与快捷键

- 快捷键仅在对应区域获得焦点时生效，不全局拦截 `Esc`。
- 命令块选择区域内的 `Esc` 仅清除块选择；Exec 面板内的 `Esc` 处理历史任务跟随。
- 主终端输入区域的按键继续遵循终端交互，其他区域不能抢占它的快捷键。

## 验收条件

- Human / Agent 标签出现在命令前，远端收到的命令不含展示标签。
- 同一主终端同时支持输入、查看命令与输出、点击块号多选和高亮，无需切换终端与块视图。
- 行号栏顶部只有红色圆形「取消全选」图标，明暗主题下均可辨认；一位、多位和最大支持块号完整显示，编号缩短后行号栏收缩。
- 主终端直接输入并按 Enter 发送，没有额外命令输入栏；选择不触发复制、终止或重复执行。
- 选中上下文可以准确传递给 Agent，保持实例隔离、边界与缺口信息，不泄露秘密。
- 关闭面板后到达新任务，面板保持关闭；查看历史任务时新任务不覆盖当前查看内容，恢复跟随后显示最新任务。
- 分别验证选择区域、Exec 面板和主终端的 `Esc` 行为，以及滚动、窗口调整、断线重连和卸载后的状态清理。
