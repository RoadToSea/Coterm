# SSH 显式提权与脚本输入

日期：2026-10-30。

状态：已实现并完成本地回归；实施与现场待验证范围见 [SSH 开发进度](../progress/ssh-plugin.md)。

## 决策

- `ssh.exec`、`ssh.read_file`、`ssh.write_file` 增加可选 `sudo: boolean`，默认 false。共享 PTY 继续沿用当前用户；独立通道仍从 SSH 登录用户启动，不复制 PTY 的进程状态。
- 提权必须显式请求。Agent 写操作仍先经过基座审批或用户开启的 Bypass；随后复用基座秘密交互，提示用户输入本次 sudo 密码。密码不接受 MCP 参数，不进入事件、账本或命令字符串。
- 交互绑定实例、操作和物理连接，60 秒过期。取消、过期、断线或连接变化后禁止恢复；秘密句柄一次性消费，不保存 sudo 密码，不复用 SSH 登录密码。
- 远端只执行一次 `sudo -k -S -p <随机提示标记> -- /bin/sh -c ...`，仅收到真实密码提示后通过通道 stdin 输入密码，限制一行；用随机就绪标记识别 NOPASSWD，避免密码或额外换行污染文件/脚本；失败、超时或结果未知不自动重试。NOPASSWD 可提交空密码。要求 TTY 或额外认证的远端 sudo 策略返回失败，用户使用共享终端处理。
- exec 接收 1–64 个脚本，总计 64 KiB UTF-8 字节。插件把脚本通过 stdin 交付固定 Shell 入口，先完整接收再 eval，避免 SSH exec 参数和多层转义的长度限制。列表项共用一个独立 Shell，首个非零状态停止。
- 文件写入仍使用原子替换与受限 mode；sudo 只改变该次文件操作的执行用户。文件工具不增加任意本地文件访问或其他协议能力。

## 验收

- 在实际 MCP `tools/list` 中验证文件工具、脚本长度与 sudo 参数；不对 MCP 新增 Token。
- 本地测试 SSH 服务执行真实 POSIX Shell，覆盖多行、重定向、长脚本、列表状态与失败停止。
- 验证审批、秘密输入、取消、连接变更和错误密码，不重复执行；所有普通事件与返回值均不含秘密。
- 验证权限文件读写、ANSI 输出、分包边界和摘要预览；运行工作区检查和相关测试。
